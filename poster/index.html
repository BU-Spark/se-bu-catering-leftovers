FreeBites

Catering Leftovers | BU Dining Sustainability

Project Goal

The Problem: Massachusetts generates over 1 million tons of food waste each year, while food insecurity continues to rise. At BU, leftover catered food is often thrown away because staff lack a fast, accessible, and real-time way to alert students.

The Solution: Create a native mobile app that lets BU Dining staff instantly post leftover events and automatically notify students. This provides a quick, reliable, and student-friendly system that reduces waste and improves student access.

Final Deliverables

  • Rebuilt and migrated the leftover alert system from the legacy web app to a mobile React Native app
  • Designed a streamlined "Create Event" flow for fast staff posting
  • Implemented RBAC to verify authorized dining staff
  • Built real-time push notification delivery
  • Developed Firestore-backed event management backend
  • Added new mobile-only features such as countdown timers

Reflections

Building a production-ready system pushed us beyond UI into deeper backend work. Our biggest challenge was setting up RBAC, implementing push notifications, and making sure real-time updates worked smoothly for staff.

Client feedback drove several iterations of the event flow and notifications, showing us how operational constraints shape design and how small usability changes can greatly improve staff efficiency.

Next Steps: Deploy to App Store and Google Play.

Future Impact

This system lays the foundation for a campus-wide leftover recovery network. With mobile-first workflows, verified staff access, and real-time student reach, FreeBites can scale across BU Dining to significantly reduce food waste.
